# Long Tướng — tải bản Android

Webgame nhập vai Tam Quốc cuộn ngang **Long Tướng**.

- **Tải APK mới nhất:** [LongTuong.apk](https://github.com/thienlangky/longtuong-download/releases/latest/download/LongTuong.apk)
- Chơi trên trình duyệt: https://longtuong.online

Cài đặt: tải file về điện thoại Android, mở file và cho phép «Cài ứng dụng từ nguồn này» nếu máy hỏi.

Trò chơi dành cho người từ 18 tuổi trở lên. Chơi quá 180 phút một ngày sẽ ảnh hưởng xấu đến sức khoẻ.
